## Description

FileForge is a toolbox for everyday file jobs that works entirely inside your browser. Nothing is uploaded anywhere: your photos and documents never leave your computer.

IMAGES
• Crop with drag handles or exact numbers, with aspect-ratio presets
• Resize by pixels or percent, with quality-preserving downscaling
• Rotate and flip
• Compress JPG, PNG and WebP with a live before/after preview and the resulting size
• Convert between JPG, PNG and WebP
• HEIC (iPhone photos) → JPG or PNG
• Text watermark with live preview (corners, centre or tiled)
• Redact: black out, pixelate or blur names, faces and card numbers on screenshots
• Remove metadata: see the camera, date, exposure and GPS location first, then strip EXIF, GPS, XMP and comments without re-encoding
• Compress to a target size, e.g. "under 200 KB"
• Favicon and app-icon generator: favicon.ico, every PNG size, HTML snippet and web manifest
• Adjust: brightness, contrast, saturation, hue, blur, sharpen, grayscale, sepia, one-click looks, live preview
• Frame, padding & corners: coloured or transparent margin, border, rounded corners, soft shadow
• Colour palette: the dominant colours as HEX, RGB, HSL, CSS variables, JSON or a swatch image
• QR code: link, text, Wi-Fi, e-mail, phone, SMS or vCard, as PNG or SVG
• Resize presets for Instagram, Stories, YouTube, Open Graph, LinkedIn, X with cover-crop or fit
• Collage and contact sheet: many photos in one grid, with a gap, background and file names
• Split an image into tiles (3 × 3 Instagram grids, banners) or fixed-size pieces
• Compare two screenshots pixel by pixel: changes highlighted and counted
• SVG → PNG, JPEG or WebP at any size, with 1×/2×/3× sets
• Right-click any image on a web page → "Edit image in FileForge"; right-click a PDF link → "Open PDF in FileForge"
• Alt+Shift+F opens FileForge from any tab

PDF
• Merge PDFs in the order you choose
• Split by page ranges (click the page thumbnails), one file per page, or into chunks
• Reorder pages by dragging thumbnails; rotate or delete pages
• Add page numbers and a diagonal text watermark (DRAFT, CONFIDENTIAL…)
• Compress: lossless (text stays selectable) or re-render scans at a lower resolution
• Remove PDF metadata: title, author, software, dates, keywords, XMP
• Images → PDF and PDF → images (PNG or JPG, 72–300 dpi)
• PDF → text or Markdown
• Crop pages: trim margins by millimetres or auto-detect the printed area
• Pages per sheet: 2, 4, 6, 9 or 16 pages on one A4 / Letter / A3 sheet, or 1 per sheet to re-flow page sizes
• Stamp an image or signature on all, first, last or chosen pages
• Extract the images embedded in a PDF at their original resolution
• Booklet: re-order pages for double-sided printing that folds into a booklet
• Fill PDF forms (text, checkboxes, choices) and save them filled or flattened

TEXT & DATA
• Markdown → PDF with a live preview and three themes
• CSV ⇄ JSON
• Format and validate JSON, with the exact position of an error
• Base64 encode and decode, for text and files
• Markdown → HTML, standalone page or fragment
• Text diff with a unified .diff export
• Checksums: SHA-256, SHA-1, SHA-512, MD5, CRC32, and verification against an expected value
• Word count, reading time and case conversion (UPPER, Title, camelCase, snake_case…), trim / dedupe / sort lines
• JWT decoder with expiry check and optional HS256/384/512 verification
• URL encode, decode and parse; regex tester with live highlighting
• Table converter: CSV, TSV, Markdown, HTML or JSON → Markdown table, CSV, HTML, JSON or SQL
• Colour converter with tints, shades and a WCAG contrast checker
• Rename files in bulk with patterns, counters, dates, find & replace and Latin-only names
• Pipeline: chain tools (resize → adjust → watermark → compress) and run them on every file at once

EVERYDAY DETAILS
• Batches show progress and can be cancelled; results download one by one, as a ZIP, copy to the clipboard, or go straight into the next tool
• Every tool remembers the options you used last time
• Interface in English and Ukrainian, light and dark theme, a home page with every tool, a command palette (Ctrl+K), keyboard shortcuts and favourite tools
• Results can be previewed in place before you download them
• Drop files anywhere on the page, paste images from the clipboard, Ctrl+Enter to run
• Side panel mode: keep FileForge open beside the page you are working on; the right-click entries then load files straight into the panel

PRIVACY AND PERMISSIONS
Everything runs locally: there is no server, no account, no analytics and no network requests. The extension needs only the contextMenus permission for the right-click entry and sidePanel to show itself in the side panel. When you use "Edit image in FileForge" on a page, it asks for access to that one site so it can read the image, and only then.

## Single purpose

Edit and convert the user's own image, PDF and text files locally in the browser.

## Permission justifications

- **contextMenus**: the "Edit image in FileForge" entry in the right-click menu of images and "Open PDF in FileForge" on PDF links and pages.
- **sidePanel**: shows the FileForge page in Chrome's side panel when the user picks "Open in side panel" or the ◨ button; the page is the extension's own, and the permission gives no access to web pages.
- **scripting**: only used when "Edit image in FileForge" is chosen on an image that exists solely inside the page (a `blob:` URL, e.g. an image editor's canvas or a pasted screenshot). A one-line script runs in that tab, after the user granted that site, to read that one image's bytes. No content scripts are registered and nothing runs on pages the user did not pick.
- **Optional host permissions (`<all_urls>`)**: requested for a single site, only when the user chooses one of those menu items there, so the extension can fetch that image or PDF. Never requested up front.
- **Sandbox page** (`app/heic-sandbox.html`): runs the HEIC decoder (heic2any / libheif), which needs `new Function`; it is isolated from the extension's privileges and only exchanges image bytes with the app page.

## Data usage

Does not collect or transmit any user data.
